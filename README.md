# 🚀 Varsha-Assistant - Android Releases

Welcome to the official repository for **Varsha AI** updates. This repository is strictly used for hosting the latest secure OTA (Over-The-Air) APK releases for the app.

## ✨ Key Features
* **Zero-Latency Offline Engine:** Instantly toggle hardware (Flashlight, Wi-Fi), make calls, and launch apps without an internet connection (0.5s response time).
* **Enterprise-Grade Security:** Biometric app-lock and `FLAG_SECURE` integration to prevent screenshots on sensitive screens.
* **Super Admin & Whitelist Mode:** Advanced Role-Based Access Control (RBAC) via Firebase Firestore to securely manage Master API keys without exposing them to public users.
* **Premium Glassmorphism UI:** Next-gen visuals with parallax blur effects, shimmer loading states, and glowing AI orbs.
* **Seamless In-App Updates:** Built-in OTA updater using Android's native DownloadManager to keep the app up to date automatically.

## 📥 How to Download
If you are a beta tester or a whitelisted user, your app will automatically notify you when a new update is available here. You can also manually download the latest `app-release.apk` from the [Releases Tab](../../releases/latest).
